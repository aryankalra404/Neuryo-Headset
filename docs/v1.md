# v1 · 26 Oct design

**Status:** retired by decision D24 in the Neuryo-Research plan (see [v2.md](v2.md) for why). Kept unchanged so the two can be compared.

**Open it:** [designs/v1/](https://aryankalra404.github.io/Neuryo-Headset/designs/v1/) · AR on Meta Quest and webcam [try-on](https://aryankalra404.github.io/Neuryo-Headset/tryon.html) work for this version.

**Source:** the team's 26 Oct design doc. Shapes and sizes the doc didn't give are marked as model estimates on the page.

## Spec
| | |
|---|---|
| EEG channels | 4 · AF7, AF8, Fz, Pz |
| Reference | TP9 and TP10 (both mastoids), linked in hardware into SRB1 |
| Ground (bias) | Fpz, disposable hydrogel snap in the centre of the forehead |
| Electrodes | Saline-soaked PVA sponge on an Ag/AgCl contact, in 3D-printed pods. Dome sponge at Fz/Pz (in hair), flat sponge at AF7/AF8 and the mastoids |
| Heart | MAX30102 PPG through a window on the forehead · heart rate, HRV, breathing |
| Motion | MPU-6050, 6-axis |
| EEG chip | ADS1299-4 · 250 samples/s · 24-bit · gain 24 · lead-off 31.2 Hz |
| Microcontroller | ESP32-S3-WROOM-1 · Bluetooth LE |
| Battery | LiPo 3.7 V 2000 mAh · 3 h or more target |
| Front module | about 105 × 55 × 19 mm, 3D-printed PETG; 4-layer 60 × 45 mm board |
| Parts cost | about ₹10,700 per headset |
| Session | about 3 min setup + 2 min test |
| Intended use | Tracks change across clinic visits. Research device; no diagnosis |

## Mannequin
Since 29 Oct, v1 sits on the same shared head as v2 (MakeHuman base mesh, CC0, 540 mm; see [head.md](head.md)), with AF7, AF8, Fpz, Fz and Pz at their measured 10-10 positions. The layout is otherwise unchanged from the design doc. Two model notes:
- The mastoid pods sit 15 mm behind the standard TP9/TP10 point so they clear this mannequin's ear.
- The heart-sensor window is placed about 2 cm from the Fpz pad, as the doc asks; its exact spot is a model estimate.

Before that, v1 used a smooth head built from formulas in the page, with electrode spots set by angle rather than measured. The webcam try-on still uses the headset shape exported from that earlier version (`neuryo-headset.glb`).
